# Carlitos Network

**CRLTS** — an independent Bitcoin-style blockchain project.

The goal is a native coin with its own chain, nodes, SHA-256 proof-of-work mining, wallets, and block explorer — not a token deployed on another chain.

See [PROTOCOL.md](PROTOCOL.md) for the initial protocol baseline and unresolved network parameters.

**Current status:** design/bootstrap stage. No mainnet, testnet, genesis block, or working wallet has been launched yet.
